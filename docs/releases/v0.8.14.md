# Agent Office v0.8.14

- **A clear sign-in page for a new browser.** The short address (`http://office.localhost:4600/`) needs a sign-in cookie that each browser gets once. A browser without it showed a bare "not found" every time; it now shows a short Korean and English page saying the browser has not signed in yet and how to do it. The page carries no token.
- **`agent-office connect` prints the sign-in address** for another browser (the short address with its token), next to the short address, with a warning not to share it.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.14/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.13.
