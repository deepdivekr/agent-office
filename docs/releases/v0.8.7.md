# Agent Office v0.8.7

- **Grok handles X research only.** The brief a Work's AI gets when Grok Build is signed in now routes posts, authors and threads from X through it and nothing else: pictures and video stay with the app's own tools, which the owner's card Work already used (v0.8.6 had offered Grok's image and video tools too).
- **The brief carries the rules measured on 2026-10-14.** One call at a time under `timeout 300`, `--reasoning-effort low`, at most 6 turns; name the search mode and operators; each search returns at most 10 posts with no next page, so split accounts into groups of 5–6 per `from:` query and split time windows; one thread fetch per selected post; no semantic search or open-ended prompts (those ran for many minutes and were cancelled); ask for JSON with a problems array. The Connections card and docs say the same.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.7/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.6.
