# Agent Office v0.8.1

- **The phone stays signed in.** Opening Office over Tailscale keeps the phone signed in for 400 days, even after the browser or home-screen app closes.
- **Notifications open Office.** A link from another app or a tapped notification opens Office instead of "not found".
- **Signed-out message.** A phone that has lost its sign-in is told to scan the QR code from `agent-office connect` again.

Changes still need the page's own origin and header, so other sites can only load a page, not act.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.1/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.0. A phone already signed in switches to the lasting sign-in the next time it opens a page; no new QR scan is needed.
