# Agent Office v0.7.2

More from the clean-install check: a new user on a fresh Ubuntu, with no AI app, skill or MCP server.

## Install

- When Chromium's system libraries are missing, the installer asks once at the terminal. It says which command runs with sudo (Playwright's `install-deps chromium`, official Ubuntu packages through apt) and that sudo reads the password, never Agent Office. "n", or no terminal, runs nothing privileged and prints the command.
- Installer messages are in English unless the system language is Korean.
- The Install button reads "Installing…" while an AI app installs.

## Runs

- A Work stopped on an AI app sign-in says to sign in to that app, not to Site login. An overloaded or rate-limited service, a used-up allowance and a time limit each say what happened and that the Work runs again by itself.
- **Run again** shows on a Work that waits for an AI app sign-in, a model or a connection, waits to retry, or has failed. A site sign-in still continues from Sites.
- The feed leaves out a run that stopped or paused before it made anything; the Work's detail keeps it.
- The Work's AI is told to install a missing tool, library or browser under the user account where later runs can reuse it, and to name what it installed.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.7.2/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.7.1.
