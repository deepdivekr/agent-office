# Agent Office v0.7.5

- The browser step asks "Will Work also use sites that need a sign-in?" and the guide asks for a site address without naming a particular site as an example.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.7.5/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.7.4.
