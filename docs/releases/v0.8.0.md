# Agent Office v0.8.0

## Profiles: a second Office on the same computer

- `agent-office --profile work connect` starts a separate Office, for example one for personal Work and one for business. It has its own:
  - data, in `~/.agent-office-profiles/work`
  - fixed port, the first free one from 4601 to 4699, chosen when the profile is made
  - MCP name, `agent-office-work`, which Codex, Claude Code, Cursor, OpenCode, Hermes and the Windows apps register next to the original
- The profile's name appears next to the logo.
- A Work running in one Office cannot start or change Works in the other.
- Both Offices run as your account, so a profile separates records, notices and addresses, not file access. For business data that other Works must not reach, use a separate Windows account or computer.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.0/install.sh | bash'
```

Saved Works, schedules and settings carry over; the Office without a profile stays where it was. The install verifier upgrades from v0.3.1 through v0.7.6.
