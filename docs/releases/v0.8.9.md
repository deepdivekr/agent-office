# Agent Office v0.8.9

- **Schedule proposals.** A Work's AI may propose a different schedule with `SCHEDULE.json`; it appears in the feed with **Apply schedule** and **Keep as is**. A cadence you write in a direction ("every 2 hours", "1시간마다") is applied at once.
- **Memory in the feed and for every AI app.** Proposals from recurring Works arrive as a feed post with **Open in Memory**. Any AI app connected to Office can read Memory with the read-only MCP tool `runtime_vault_list`.
- **Edit or delete notes.** On the Memory page a proposal can be approved as it is or edited first, and any note can be deleted.
- **Completion checks a run can meet.** Intake no longer writes a separate check for each of several mutually exclusive outcomes, nor checks about setting up the schedule or delivery, which Office owns.

See [docs/vault.md](../vault.md).

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.9/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.8.
