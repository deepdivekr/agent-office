# Agent Office v0.7.3

From installing v0.7.2 on a fresh Ubuntu with nothing on it.

- Before asking for sudo, the installer says which password it is: not the Windows one, but the one made when WSL Ubuntu first started. If it is forgotten, PowerShell can change it with `wsl -u root passwd <user>`.
- `agent-office connect` prints its summary in the system language, like the installer: Korean when the system language is Korean, English otherwise.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.7.3/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.7.2.
