# Agent Office v0.7.4

## Aside is recommended

- The browser step asks whether Work will also use sites that need a sign-in. Yes opens "Connect your own browser · recommended", and the guide walks through downloading Aside, turning on its CLI in Settings → Developers, connecting and allowing it, then adding a site to sign in to.
- Aside and BrowserOS Neo say what they are for: when the default browser tool fails, Work moves there by itself.
- A new Work that names a site needing a sign-in (a known sign-in site, or one you registered) says so below Start while Aside is not connected, with a link to connect it.

## One server notice per check

- Works on one server that change in the same check are sent as one message per messenger destination, not one each. For example, services that recover together read `[회복] Hetzner VM · 업무 3개` with their names and `모두 정상입니다.` A single Work keeps its three-line notice.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.7.4/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.7.3.
