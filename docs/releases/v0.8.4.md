# Agent Office v0.8.4

- **Telegram gets a result post by post.** When a Work's message is split into posts by `---` lines and each post names its picture (`![설명](01_card.png)`), Telegram receives each post's text and then its picture, one post after another, instead of one long message followed by every picture.
  - The Work's title and state go on the first post and the result id on the last. A picture no post names still follows at the end under its file name. A message that names no picture is sent as one message, as before.
  - The feed shows the post text without the picture lines, with the pictures below it.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.4/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.3.
