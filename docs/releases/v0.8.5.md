# Agent Office v0.8.5

- **Nothing new, no message.** A repeating Work whose AI app leaves `DELIVERY.md` empty is saying this run has nothing for you. Office keeps that run in the Work's history, and sends nothing: no Telegram, Slack or Discord message, no post in the feed and no push notification. Before, the app's final reply was sent instead.
  - To use it, tell the Work: "When there is nothing new, leave DELIVERY.md empty."

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.5/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.4.
