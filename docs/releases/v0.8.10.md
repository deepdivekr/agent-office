# Agent Office v0.8.10

- **Memory stays small in the AI's context.** A run gets boundaries first, then the notes its Work names, then general ones, within about 1,500 characters (it was up to 8,000); what does not fit is one line pointing at `runtime_vault_list`, so the AI reads it only when it needs it. Measured on the owner's Works: about 2,200 characters instead of about 4,200.
- **Once per conversation.** A recurring Work that continues the same conversation gets Memory in its first run and again only when the notes changed; otherwise one line says it is unchanged.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.10/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.9.
