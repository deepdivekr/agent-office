# Agent Office v0.8.8

- **Memory (the Office vault).** Knowledge every AI app that works for you shares across Works: how results are written, which sources count, what needs your say, how a tool should be used, where things are on this computer. One Markdown note per fact in this Office's own state folder. When a Work runs, the notes that apply (those without keywords, and those whose keywords the Work names) go to its AI with the request; the Work's own directions still win. See [docs/vault.md](../vault.md).
- **Memory page.** Add, edit, retire and restore notes, and approve or decline what runs proposed. A run may save `VAULT.json` with up to five lessons it thinks hold beyond its Work; they arrive as one feed post and apply only after you approve them.
- **A direction for every Work.** When sending a direction to a Work, **Apply to every Work · keep in Memory** also keeps it as a note, so other Works get it from their next run.
- **Tool rules are notes now.** How to word X searches through Grok Build moved from code into shipped notes you can change without a release; the Grok brief keeps only how to call the command.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.8/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.7.
