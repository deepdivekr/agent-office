# Agent Office v0.6.0

## The feed: where results come together

- Every output lands in one stream, newest first: results Office saved, messages your server bots sent, the last answer of an attached conversation, and send records from outside Office.
- Each output is shown by its kind: writing reads as an article, options sit side by side, an email draft waits for your check, spending shows a number and a chart, and there are checklist, event and price-change cards.
- A Work that needs a choice or a check is pinned at the top. Buttons that send, submit or approve ask in a sheet first, then reach the Work's own AI. A reply under a result goes to the same Work.
- A picture opens full screen; a post's name, title and preview open what they show; Files goes to the files.
- Push notifications reach the phone when it is turned on.

## One AI per Work, and you can move it

- Every Work runs on the AI chosen at intake (Codex or Claude Code), form drafts and record updates included. Office's own host executor no longer takes over a Work; only coding orchestration and imported original runtimes keep their own path.
- **Change AI:** between runs, move a Work to the other app, model or effort from its detail. Office never does this by itself.
  - The change sheet reads the earlier runs for what the new app lacks (Codex's built-in image generation, an MCP server, a skill) and drafts a handoff direction that goes with the change.
  - The next run starts a new session on the new app with the same Work folder and records.
- A direction needs no step selection; it goes to the Work's session as written.
- Revising a registered deliverable goes to the same Work, not a new one (MCP instruction).

## Screens

- **Sidebar:** Feed and Work. All, Needs you, Running, Recurring, On hold, Ended and Hidden are tabs inside Work, so the Feed shows none of them.
- **Board:** On hold is work with something left that does not run now; Ended has nothing left. A Work never started waits under Needs you, and Ended Works older than 30 days fold away.
- **Timeline:** a small legend, server timer runs and periods.
- **Result history** shows the message the owner gets, not the check record with its JSON files.
- **Phone:** home screen icon and manifest, a menu for tools, language and theme, back and forward by swipe, a back button at the top left, board columns that fit the screen.

## Bring work in

- **AI conversations:** Claude Code and Codex, from the desktop apps or a terminal, one tab per app. A Windows app conversation can be continued from Office.
- **Import from another app:** a lean answer format and errors that say what went wrong.
- **Server services:** the found services are listed, the server address stays out of notices and lists, server settings live in the server registration, server Works get a conversation and recurring or always-on states, and a failing timer job that runs again is one notice.

## Other changes

- Media executor for transcription, subtitled video and narration.
- Old runs' working files are cleared from Work folders; the record of reported items stays.
- `agent-office connect` prints usable addresses with a QR code for the phone and opens the browser for the first setup only.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.6.0/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1, v0.4.0 and v0.5.0.
