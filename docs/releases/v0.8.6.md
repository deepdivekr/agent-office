# Agent Office v0.8.6

- **Grok Build in Connections.** xAI's Grok Build CLI appears next to Codex, Claude Code, OpenCode, Cursor and Hermes: install from the official script, sign in with the Grok subscription (device code or browser), register Office's MCP. Office reads only what `grok models` reports; the credential store is never opened.
- **A tool package for every Work.** Grok Build does not take Works. Signed in, every Work's AI is told how to call it one-shot for X research (keyword, semantic and user search, thread fetch), image generation and editing, and video from an image or references, on the owner's Grok subscription. Measured on the first day: a `--tools` allowlist hides the X tools and MCP discovery sends the agent looking elsewhere, so the brief fixes the flags that worked.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.6/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.5.
