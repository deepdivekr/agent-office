# Agent Office v0.8.2

- **Change a schedule from the Work.** Recurring Work shows the schedule in words, such as "Every hour" or "Every week Mon·Wed·Fri 09:00", with a Change schedule button. A Work that does not repeat has Add a schedule.
  - Choose an interval in minutes, hours or days, clock times every day or on chosen weekdays, or turn repeating off. A save applies at once.
- **A direction that names a cadence opens the editor.** After you send a direction such as "run it every hour", the editor opens filled in with that cadence. The direction still reaches the Work's AI as written, and the schedule changes only when you save it.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.2/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.1.
