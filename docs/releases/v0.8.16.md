# Agent Office v0.8.16

- **Videos play in the feed.** A Work's result left out every file over 16 MB, so a typical Reel (35 MB) never reached the feed and its player had nothing to show. A video or sound file up to 1 GB now enters the result with its hash, read in pieces, and the feed plays it from ranges as before. Other files over 16 MB are still listed in the result text and not offered for download.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.16/install.sh | bash'
```

Saved Works, schedules and settings carry over. A result saved before this version keeps its files; the next run of that Work includes its video. The install verifier upgrades from v0.3.1 through v0.8.15.
