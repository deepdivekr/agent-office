# Agent Office v0.8.15

- **A wider collection period for one recurring Work.** A recurring Work that collects the latest items still covers the run date and the day before it in every run. The owner can now widen one Work to the last 3, 7, 14 or 30 days from the Recurring Work panel in its detail (`Collection period`). The run and its verification are both told the wider range; a model never sets it. The change is recorded in the Work history.
- **Aside stays reachable after the starting shell closes.** On WSL a service kept the Windows interop socket of the shell that started it; once that session ended, every Windows launch failed and every Work found Aside "not answering" and fell back to a headless browser. The Control Center and MCP services now start Windows programs through the distro's own interop socket.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.15/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.14.
