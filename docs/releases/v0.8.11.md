# Agent Office v0.8.11

- **Short prompts for continued runs.** A recurring Work that continues its conversation got the full instruction again every run (one Work: 12,000 characters of directions every hour). Now it gets a short prompt (this run's folder, what Office settled for this run, the completion conditions) while nothing changed. A new direction, a changed condition or vault note, or a previous run that did not end verified sends the full instruction again.
- **A new conversation past half the window.** Office reads the client's own session file before continuing; when the last turn used half the context window or more, the run starts a new conversation with the full instruction instead of relying on compaction. Measured on the owner's AI news Work: one conversation since 10-08, 62 turns, six compactions, last input 329K of 475K tokens.

See [docs/vault.md](../vault.md#recurring-conversations).

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.11/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.10.
