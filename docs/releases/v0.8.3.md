# Agent Office v0.8.3

- **Import suggestions show why.** Each suggested folder lists what it was judged on: the systemd service with its description, command and timer schedule, the crontab line, the GitHub Actions workflow and its cron, the timer file, the scheduler or messenger library. Secret-looking values in command lines are hidden.
- **Only what clearly runs.** A folder is suggested when systemd, crontab, a GitHub Actions schedule or an always-on container runs it, or when it defines a schedule next to code that uses it. A messenger library alone is not enough, and installed but stopped systemd units do not count.
- **Nothing that is already a Work.** Folders already imported and units an Office server Work watches are left out.
- **No conversations in the list.** Continuing a conversation stays in Attach an AI conversation.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.3/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.2.
