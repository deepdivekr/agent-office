# Agent Office v0.8.13

- **Old schedule conditions leave the Work.** A Work defined before v0.8.9 could carry a completion condition about Office's own settings, such as "the daily schedule is active" or "the Telegram chat is set as the delivery target". Changing the schedule did not touch it, so after the owner set the AI news Work to hourly the condition still said daily; a new conversation read it as its task, stopped for review and proposed switching back to daily 09:00. Office now removes such conditions from the Work as a new revision: when the owner changes the schedule, when a schedule proposal is applied, and in a sweep at start and every 15 minutes (a Work with a run in progress waits for the next sweep). A run never receives one.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.13/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.12.
