# Agent Office v0.7.0

## Easier first setup

- The first `agent-office connect` opens Settings instead of the feed, at the AI app step while no app is signed in and connected.
- A guide lights the one thing to press next in each step (install, sign in, connect, next), with one line on why and the step count. It ends with links to find Works to bring in and to the feed. It shows only until setup is saved or when asked for with `?welcome=1`, and "Hide guide" turns it off for good. An install that is already set up never sees it.

## Codex and Claude Code on WSL and Windows

- Each AI app card shows the WSL side and the Windows side next to each other.
- When the app is on both, pick both, WSL only or Windows only; one Connect registers the choice. The Windows side is registered through the app's own `mcp add` with the `wsl.exe` bridge; no config to paste by hand.
- A side without the app shows its install and sign-in commands to copy (a WSL terminal or Windows PowerShell).

## Find what already runs on this computer

- Import opens with suggestions, found read-only and without a model call, and shown on this screen only:
  - folders of your Claude Code and Codex conversations that run by themselves (GitHub Actions schedule, crontab or systemd lines, timer files, scheduler or messenger libraries, always-on containers), with their GitHub repository and recent topic: "Bring it in" starts the address analysis;
  - recent conversations to attach as Works;
  - Hermes jobs on this computer, and registered OpenClaw servers with nothing linked yet.
- Office's own runs and the clients' internal conversations are left out; `.env` is never read.

## Fixes

- A reply saved again when a direction paused a run no longer shows as a new reply above your latest direction.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.7.0/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1, v0.4.0, v0.5.0 and v0.6.0.
