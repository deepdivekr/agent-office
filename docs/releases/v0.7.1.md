# Agent Office v0.7.1

A fix release from installing v0.7.0 on a clean WSL Ubuntu with nothing on it, as the README says.

## First run

- The first `agent-office connect` opens Settings again; v0.7.0 stopped with `CONTROL_CENTER_URL_INVALID` and printed no address.
- `agent-office connect --open` and `--no-open` work.
- A fresh install opens at the AI app step, not at Work defaults.
- The guide goes install, sign in, connect: the WSL app that runs Work comes first, and connecting the Windows app follows.
- A Korean browser opens in Korean until you pick a language.

## Signing in from Settings

- Codex shows the one-time code to enter next to the sign-in link.
- Claude Code shows its sign-in link, and the card takes the code the sign-in page shows and hands it to Claude Code.

## Runs

- A Codex run that stops because the model is at capacity waits and runs again, instead of showing "sign-in needed". The client's own error decides; its log lines no longer read as an expired login.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.7.1/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1, v0.4.0, v0.5.0, v0.6.0 and v0.7.0.
