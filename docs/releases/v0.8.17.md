# Agent Office v0.8.17

- **Files DELIVERY.md links to are handed over.** A turn's result holds the files that turn made. A turn asked to hand over something an earlier turn already made (a finished video) wrote only DELIVERY.md, so the unchanged video stayed out of the result and the feed had nothing to play. A file that DELIVERY.md links to (`![…](file)` or `[…](file)`) is now part of the turn's result even when it did not change.

## Upgrade

Finish active work, close MCP clients and the Control Center, and rerun the installer:

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-office/v0.8.17/install.sh | bash'
```

Saved Works, schedules and settings carry over. The install verifier upgrades from v0.3.1 through v0.8.16.
